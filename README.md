# Oil & Gas Production Management System - Sudan

**CS50 Final Project**
**By: [FAROUG AMIR FAROUG HUMAD] - , Sudan**

### About The Project
A system to manage oil wells in Sudan. It helps to:
- Register new oil/gas wells
- Record daily oil and gas production
- Show dashboard with all wells
- Generate reports by dates

### Features
1.  **Add Well:** Add new well with name, location and type
2.  **Add Production:** Record daily production (Oil in Barrels, Gas in MCF) with date
3.  **Dashboard:** View all wells and total production
4.  **Reports:** View production history by dates

### Built With
- Python (Flask)
- SQLite
- HTML / CSS / Bootstrap
